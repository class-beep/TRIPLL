Smart Travel Planner
Project Overview
Smart Travel Planner is a full-stack web application that helps users plan and manage trips efficiently. The application provides an interactive user interface for travel planning and a backend system for handling data, user requests, and application logic.

Features
Create and manage travel plans
User-friendly interface
Secure backend processing
Data storage and retrieval
Responsive design
Trip organization and planning
